# Concepts

Shared domain vocabulary for this project — entities, named processes, and status concepts with project-specific meaning. Seeded with core domain vocabulary, then accretes as ce-compound and ce-compound-refresh process learnings; direct edits are fine. Glossary only, not a spec or catch-all.

## Review run

A review run is one proposal's independent journey through expert drafts, peer feedback, revisions and an optional final synthesis.

## Expert review

An expert review records a particular perspective on the proposal, with a draft and, when successful, a revision informed by peer feedback.

## Partial result

A partial result contains usable expert work but is missing some requested review, feedback or synthesis because execution did not fully succeed.

It must remain distinguishable from a complete review and from a failure with no usable expert work. A final synthesis is not required for partial results to be useful.

## Recovery reference

A recovery reference identifies an existing review run so the browser can retrieve it after an interrupted connection or page reload.

Temporary unreachability does not invalidate this reference; confirmed absence does.
